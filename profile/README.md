# 合尘猫 · SavantCat

**合尘猫（savantcat.cn）** 是面向中小企业的企业知识库与 AI 客服服务商：把企业内部的知识做成能答准、能过 GB/T 47746—2026 国标自查的 AI 客服。

一个人 + 一个 AI 分身。不卖 SaaS 账号，只交付「能跑起来、能过检查」的东西。

- 官网：<https://savantcat.cn>
- 合规问答库（条款级，公开只读）：<https://savantcat.cn/answers/>
- 国标自查清单（GB/T 47746—2026，61 项）：<https://savantcat.cn/compliance-check.html>
- 面向大模型的语料：<https://savantcat.cn/llms-full.txt>

## 在做什么

- 企业知识库部署：盘点 → 灌库 → 兜底转人工 → 每周优化 → 过国标自查
- AI 客服达标：对照 GB/T 47746—2026（2026-09-01 实施）逐条自查
- GEO / AEO：让企业的官网和内容能被大模型检索到、引用到
